## 🚀 What I'm Building

### 🧠 AVEN — Autonomous Virtual Execution Navigator

A long-term personal AI system designed as a **second brain + execution layer**.

AVEN is being designed around AI agents that can understand a task, use tools, maintain context, and execute workflows instead of simply responding to prompts.

**Direction**

`LLMs` → `Agents` → `Tools` → `Memory` → `Automation` → `Execution`

Planned capabilities include task orchestration, reminders, notes, study assistance, interview preparation, web research and integrations.

**Stack:** `Python` `LLMs` `AI Agents` `MCP` `Groq` `Gemini` `NVIDIA NIM` `OpenRouter` `Supabase`

---

### 🏥 Consilium — Multi-Model AI Deliberation

A research-oriented **AI council for medical question answering**.

Instead of relying on a single model response, Consilium explores a deliberative architecture where multiple AI components can contribute to an answer before a final response is produced.

**Focus**

- Multi-model deliberation
- RAG / document-grounded reasoning
- Safety-first response pipeline
- Structured AI workflows
- Research and evaluation

**Stack:** `Python` `RAG` `LLMs` `Groq` `Claude` `Vector Search`

→ **[View the repository](https://github.com/weird-ragazzo/RAG-Documnt-Q-A-Assistant)**

---

### 🎤 InterviewSage — AI Resume & Interview Platform

My final-year project direction: an **AI-driven resume optimization and automated interview platform**.

The goal is to connect resume analysis, job requirements and AI-powered interview workflows into one system.

**Core idea**

`Resume` → `Job Analysis` → `Skill Gaps` → `Personalized Questions` → `AI Interview` → `Feedback`

**Focus:** `Generative AI` `RAG` `NLP` `AI Agents` `Resume Intelligence`
